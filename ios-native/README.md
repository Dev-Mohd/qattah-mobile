# قطّه — نسخة Swift (iOS)

إعادة بناء تطبيق قطّه بلغة Swift و SwiftUI بدلاً من Flutter.

## التشغيل لأول مرة

```bash
brew install xcodegen cocoapods
```

```bash
cd ios-native && xcodegen generate && pod install
```

```bash
open Qattah.xcworkspace
```

افتح دائماً ملف `Qattah.xcworkspace` وليس `.xcodeproj`.

لتشغيل اختبارات منطق الحساب وحدها بدون Xcode:

```bash
cd ios-native/Packages/QattahKit && swift test
```

## التحديث من نسخة Flutter بدون فقدان بيانات

- **معرّف الحزمة نفسه** `qattah.com.qattah`، فتصل النسخة الجديدة كتحديث عادي في App Store.
- **قاعدة البيانات نفسها** `Documents/qattah_secure.db`، مشفرة بـ SQLCipher 4 بنفس مفتاح Flutter. المفتاح يُقرأ من Keychain: الخدمة `flutter_secure_storage_service` والحساب `qattah_database_key_v1`.
- **ترحيل الجداول:** يتم عبر `DatabaseMigrator` من GRDB. كل تعديل على الجداول إضافي فقط، والأعمدة القديمة تبقى.

## ما تم إصلاحه مقارنة بنسخة Flutter

| المشكلة في Flutter | الحل في Swift |
|---|---|
| نسخة غير مشفرة `qattah_plain_backup_*.db` تبقى على الجهاز | تُحذف عند أول تشغيل |
| مفتاح التشفير `ThisDeviceOnly`، فتضيع البيانات عند الانتقال لجوال جديد | يُنقل المفتاح مع النسخ الاحتياطية المشفرة، ويظهر مسار استعادة واضح بدل التوقف |
| ضياع الهللات (100 على 3 = 99.99) | الحساب بالهللة كأعداد صحيحة، والباقي يُوزَّع على الحاضرين |
| أعضاء لهم نفس الاسم تُدمج أرصدتهم | الربط بالمعرّف فقط، والاسم يُستخدم عند عدم وجود معرّف وبشرط ألا يتكرر |
| الأرصدة لا تتحدث بسبب الكاش | `ValueObservation` يحدّث كل الشاشات تلقائياً بعد أي تعديل |
| السداد يُحسب بتاريخ إدخاله | عمود جديد `paid_on` لتاريخ السداد الفعلي |
| حذف عضو يفصل حسابه عن وجباته | العضو الذي له سجل يُخفى فقط ويبقى حسابه محفوظاً |

## تحسينات تجربة المستخدم (المرحلة 1)

- **تسجيل أسرع:** يختار التطبيق نفس حضور آخر مرة لنفس نوع الوجبة، ويحسب المبلغ الكلي من السعر المعتاد × عدد الحاضرين. ويختار نوع الوجبة حسب الوقت (فطور قبل 11 صباحاً).
- **نصيب كل شخص يظهر قبل الحفظ،** مع اهتزاز خفيف عند اللمس والحفظ.
- **رسالة جاهزة لواتساب** فيها من عليه ومن له، و**تذكير فردي** لكل عضو بالسحب على اسمه.
- **سداد سريع:** المبلغ الكامل يُعبّأ تلقائياً، مع زر للنصف، ويظهر الرصيد بعد السداد قبل الحفظ.
- **تراجع** بعد حذف أي وجبة.

## الهيكل

```
ios-native/
├── project.yml              ← ملف XcodeGen (يولّد مشروع Xcode)
├── Podfile                  ← GRDB + SQLCipher
├── Packages/QattahKit/      ← منطق الحساب: Money والتقسيم والأرصدة والاقتراحات والرسائل، مع اختباراته
├── Shared/Database/         ← قاعدة البيانات: الفتح والمفتاح والترحيل والقراءة والكتابة
├── Qattah/                  ← واجهات SwiftUI
└── QattahTests/             ← اختبارات قاعدة البيانات
```
